Bundled runtime notices

Benji is distributed under the licence in Benji-LICENSE.txt.
CPython and transitive dependency notices are preserved in Python/ from the pinned full PBS archive. PYTHON.json records their attribution and dependency metadata, including license_paths for extension modules. No pip command is run by this builder or the engine. The upstream full install prefix is retained, including its unused development files and package tooling.

The Mozilla CA certificate data, extracted by curl, is unmodified and is provided under MPL 2.0. The complete licence is Mozilla-MPL-2.0.txt. Source and extraction details: https://curl.se/docs/caextract.html and https://curl.se/ca/cacert-2026-11-05.pem . Certificate data source: https://github.com/mozilla-firefox/firefox/blob/release/security/nss/lib/ckfw/builtins/certdata.txt . The pinned input digest and extraction date are in distribution.json. This app uses an explicit CA file and does not claim macOS Keychain trust integration.
