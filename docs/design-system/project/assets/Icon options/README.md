# Icon options

24 SVGs: for each of eight concepts, `<concept>-icon.svg` (light appearance, 1024 × 1024, 824-pt tile), `<concept>-icon-dark.svg` (dark appearance) and `<concept>-menubar.svg` (18 × 18 template glyph, single ink #000000). Concepts: notch-pebble, pebble-v2, pebble, ripple, notch, lettermark, pause, breeze. All are proposals; see the IconOptions component for how they relate. Mint is #00c7be (light) and #66d4cf (dark); tiles are #000000, #1c1c1e or #eef3f2.


**Update (D-137, 2026-11-02):** the adopted icon is **Exchange**, added here as `exchange-icon.svg`, `exchange-icon-tinted.svg`, `exchange-icon-clear.svg`, `exchange-menubar.svg` (idle) and `exchange-menubar-working.svg` (halves closed). The three pebble concepts (`notch-pebble`, `pebble-v2`, `pebble`) are retired and kept as history; their art is not part of this repository.
