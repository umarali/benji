# IconOptions

Eight app-icon options for Benji, each with a light icon, a dark icon and a menu-bar template glyph, shown at Dock, list (32 and 16 px) and menu-bar sizes. Proposals for choosing. **Decided 2026-10-30: Pebble v2 (D-59)**; the finished set is in Logos.

**How they relate.** All eight share one base: a macOS 824-pt tile, Benji mint (`system-mint` / `benji-mint`) against `notch-black`, round ends, no faces or frost. They differ in which part of the Benji story they tell:

- **Object** (Notch + Pebble, Pebble v2, Pebble, Calm ripple): Benji as the calm thing you call. The pebble is already in the system (cover, menu-bar glyph), so it adds no new vocabulary; the ripple's ring echoes `PointerHighlight`.
- **Place** (Notch): where Benji lives and "invisible until called". On its own it pictures Apple hardware; it works best as the top half of a combined mark.
- **Word** (Lettermark c, Two lines, Breeze): lifted from the wordmark's rounded strokes; the two lines also match `MicMeter`'s pills. Risks: a lone letter is generic, two bars read as pause, curls read as wind.

**Notch + Pebble** joins the Object and Place families: the stone rests under the notch, the same composition as the cover, so app icon, cover and notch object tell one story. Its menu-bar glyph is the slab over the stone.

**Use**
- Pick one option per family to keep comparing; the final icon is rebuilt in Icon Composer as a layered macOS 26 icon (light, dark, tinted, clear) from the chosen SVGs.
- The menu-bar glyph must be a single-ink template (`#000000`); macOS tints it, as the dark-bar column shows.

**Don't** put a mint dot inside the notch (it reads as the camera light), use gradients for depth, or add a face.
